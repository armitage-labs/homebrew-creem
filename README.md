# Creem CLI Homebrew tap

Official Homebrew distribution of [Creem CLI](https://github.com/armitage-labs/creem/tree/main/packages/cli).

## Install

```sh
brew tap armitage-labs/creem
brew install creem
creem --help
```

For CLI usage and alternative installation methods, see the
[CLI documentation](https://docs.creem.io/code/cli).

## Upgrade

```sh
brew update
brew upgrade creem
```

## Uninstall

```sh
brew uninstall creem
brew untap armitage-labs/creem
```
